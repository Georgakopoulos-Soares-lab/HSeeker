About HSeeker

HSeeker is an open-source tool for detecting H-DNA-forming mirror repeat structures in DNA sequences. It is validated against 39 experimentally confirmed sequences from 28 peer-reviewed publications spanning 1986–2024, achieving 100 % sensitivity for genuine intramolecular H-DNA.

Run a detection GitHub

What is H-DNA?

H-DNA is an intramolecular triplex structure formed when one strand of a homopurine–homopyrimidine mirror repeat folds back and invades the complementary duplex, creating Hoogsteen or reverse-Hoogsteen hydrogen bonds with the purine strand of the remaining double helix. Four conditions are required for H-DNA formation:

  • Mirror symmetry — the purine/pyrimidine pattern must be palindromic around the hinge point
  • Negative supercoiling — torsional stress drives strand separation and triplex folding
  • Sufficient arm length — typically ≥ 16 bp total (≥ 8 bp per arm) for stable folding
  • Sequence purity — high GA or CT content (≥ 80 %) in each arm

The two main isomers

H-r

Purine motif. The purine (GA-rich) strand folds back. Forms G·G:C and A·A:T base triplets. Favored at neutral pH in the presence of Mg²⁺ or Mn²⁺.

H-y

Pyrimidine motif. The pyrimidine (CT-rich) strand folds back. Forms C·G:C⁺ and T·A:T base triplets. Favored at low pH. Includes H-y3 and H-y5 sub-isomers.

How HSeeker Works

HSeeker implements a center-outward mirror-repeat extension algorithm compiled as a CPython C extension for maximum throughput. The core scan runs in native C with the GIL released, enabling efficient parallel processing of large FASTA files.

The scan algorithm

  1. For each candidate hinge position and spacer length (0 to maxspacer), place a left pointer at the hinge and a right pointer immediately after the spacer.
  2. Extend both pointers outward simultaneously, one base at a time.
  3. At each step, check that the base pair satisfies the mirror symmetry criterion (left arm base is the Watson-Crick complement of the right arm base, read in opposite directions).
  4. Track the running GA purity and CT purity of the right arm. Extension stops when either falls below the purity threshold or mirror mismatches exceed the mismatch threshold.
  5. Record a hit if the final arm length ≥ minrep.
  6. After scanning all positions, optionally remove overlapping hits — keeping the longest arm, with shorter spacer as tiebreaker.

Key invariant: every hit satisfies start + (2 × arm_length + spacer_length) − 1 = end, where coordinates are 1-based and inclusive. The mirror is always centered on the hinge, not on an arm midpoint.

Parameter Modes

HSeeker exposes five parameters that control detection sensitivity and specificity. Three curated presets cover the most common use cases:

Preset minrep maxrep maxspacer purity mismatch Sensitivity False-positive rate
Default 65070.800.20 97.2 % (35/36) 100 % (3/3 FP)
Recommended ★ 85070.800.20 97.2 % (35/36) 0 % (0/3 FP)
Relaxed 4100100.700.30 100 % (36/36) 100 % (3/3 FP)
minrep

Minimum arm length in base pairs. The most important parameter for specificity. Raising from 6 to 8 eliminates all false positives on the validation set without losing any confirmed H-DNA sites.

maxrep

Maximum arm length cap. Set to 50 by default. Long repeat sequences (e.g. (GAA)₆₆) will be reported as arm = 50 bp — the detection is correct but the true arm length is ≥ 50 bp.

maxspacer

Maximum hinge/spacer loop length in bp. Setting this to 0 restricts detection to perfect mirror repeats with no central loop.

purity

Minimum GA or CT fraction in each arm (0–1). Five confirmed H-DNA sequences sit exactly at 80 % — this threshold should not be raised above 0.80 without risking loss of biologically important sites.

mismatch

Maximum fraction of mirror-position mismatches tolerated (0–1). Complements purity: a site passing both thresholds has adequate arm composition and structural symmetry.

remove_overlaps

When enabled, overlapping hits are deduplicated by keeping the longest arm. Ties are broken by shorter spacer. Disable to see all raw hits from the center-outward scan.

Validation

HSeeker was validated against 39 sequences — 36 experimentally confirmed H-DNA-forming motifs and 3 non-forming controls — drawn from 28 peer-reviewed publications spanning 1986–2024 across 7 organisms and 9 disease contexts. Experimental evidence includes S1 nuclease cleavage, chemical probing, 2D-gel electrophoresis, genome-wide S1-END-seq and S1-seq mapping, and polymerase stalling assays.

Key finding: HSeeker achieves 100 % sensitivity for genuine intramolecular H-DNA across all 35 confirmed sequences (the single missed sequence, G10TTAA_AG5, is an intermolecular TFO control — architecturally distinct from intramolecular H-DNA and its non-detection is correct). At minrep=8, the false-positive rate drops to 0 % on the non-forming control set.

Why minrep=8 is recommended

The default minrep=6 produces false positives on three BCL2 MBR mutants that experimentally do not form H-DNA. These sequences carry short G-rich sub-segments (arm 6–7 bp) satisfying the mirror criterion but too short to fold into a stable triplex. Crucially, arm length — not mirror quality — is the discriminating feature:

Limitations

  • Sequence-based only. HSeeker predicts H-DNA-forming potential from primary sequence. H-DNA formation in vivo requires negative supercoiling; the tool does not model supercoiling density, chromatin context, pH, or ionic conditions.
  • Specificity estimate is a lower bound. Only 3 non-forming controls are included in the benchmark, all from the same locus (BCL2 MBR). The 0 % false-positive rate at minrep=8 should not be extrapolated directly to genome-wide specificity.
  • maxrep cap. The default maxrep=50 truncates arm length reporting for very long repeats. Arm length will be reported as 50 bp for sequences with a true arm > 50 bp — detection is unaffected but the exact value is a lower bound.
  • poly-dG·dC boundary class. H-DNA formed via poly-dG·poly-dC third-strand invasion (rather than intramolecular mirror-repeat folding) may be detected incidentally but this structural class requires a separate computational approach.

## Reviewer comment (verbatim)

> There is an important risk of circularity/overfitting in the stability-score validation. The authors
> determine an "optimal classification threshold" using Youden's J statistic and subsequently evaluate
> discrimination on the same benchmark. Figure 3 then reports an apparently excellent stability-score
> AUC of 0.981 and a Youden-selected operating threshold, while the resulting confusion matrix improves
> the MCC substantially. This is not an independent assessment of predictive performance. The threshold
> must be determined using training data and evaluated on independent test data, or through
> appropriately nested cross-validation/bootstrapping. Given the small dataset,
> leave-one-study/family-out validation would be especially informative. The present AUC and threshold
> should not be described as demonstrating generalizable classification performance until this issue is
> addressed.

## Response text

We agree, and we thank the reviewer for pointing this out. We re-evaluated the score threshold exactly
as suggested, on the revised balanced benchmark (130 records, 65 forming / 65 non-forming). Within each
training fold we selected the threshold that maximised Youden's J and applied it only to the held-out
records, using repeated stratified 5-fold cross-validation (20 repeats), leave-one-family-out and
leave-one-study-out validation.

A threshold chosen this way never improved performance. Out of fold it gave MCC 0.949 (5-fold,
95 % CI 0.937–0.961) and 0.955 (leave-one-family-out and leave-one-study-out, 0.898–1.000), against
0.970 (0.925–1.000) for HSeeker's call without any threshold. The threshold removed no false positive,
because after the purity requirement no non-forming record in the benchmark has any candidate, and out of
fold it lost forming records whose score fell below a threshold learned without them. For the same
reason the score's AUC on this benchmark (0.985) only restates the detection result: it equals
(1 + sensitivity) / 2.

We therefore no longer use or report a score threshold. HSeeker calls a sequence H-DNA-forming when it
contains a candidate that passes the detection criteria, and the stability score is reported as a
heuristic ranking of candidates (see our response to comment 4). We removed the Youden-selected
threshold, the in-sample AUC and the threshold-based confusion matrix from the manuscript (former
Figure 3, now replaced), and the web interface no longer labels sites with score ≥ 50 as "stable". The
out-of-fold analysis and its code are deposited (`analysis/scripts/run_score_threshold_oof.py`,
`analysis/results/score_threshold_oof/`).
